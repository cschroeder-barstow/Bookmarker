Bookmarker is a free, open-source, lightweight bookmark manager.


**How to use:**
<br>
To use the bookmark manager, click the add bookmark button and enter the website details
example: 
```
Title:
e.g. GitHub
URL:
https://example.com or app://link
Image URL optional:
https://example.com/icon.png
```
( Note: you can also add apps with app:// )
