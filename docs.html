01 / orientation

Quick start

Bookmarker is a free, open-source, lightweight bookmark manager for links you want to reach quickly. It runs as a client-side web app: your bookmarks stay in this browser, while the main screen remains useful for both a handful of shortcuts and a much larger collection.

Save a destination

Use Add bookmark to create a card with a title, URL, optional image, and one or more tags.

Find it later

Search by title, select a category, or choose a sort mode to narrow a busy collection.

Keep data portable

Download save data as JSON before clearing site storage or changing browser profiles.

Clean up automatically

Temporary bookmarks remove themselves after their chosen date and time.

02 / create

Add a bookmark

Open Add bookmark in the upper-left area of the app. Each field has a distinct job and the form accepts both normal web destinations and custom app-style links.

FieldWhat to enterHow it is used
TitleA recognizable name such as GitHub or Design references.The card label and the text searched by the search field.
URLA complete address such as https://example.com or app://link.Opens in a new browser tab or hands a custom scheme to the operating system.
Image URLAn optional direct image URL such as https://example.com/icon.png.Becomes the card artwork. Leave blank to use automatic site-icon fallback.
TagsComma-separated labels such as work, tools.Creates category filters. Empty tags become Other.

A reliable first bookmark

  1. Choose a title you would naturally type when searching later.
  2. Paste the complete URL, including https:// where appropriate.
  3. Use two or three broad tags instead of a unique tag for every item.
  4. Save it, then open the card once to confirm the destination.

URL safety: empty addresses and unsafe protocols including javascript:, data:, vbscript:, and file: are rejected intentionally.

03 / structure

Organize and filter

Every tag becomes a filter in the category bar. Display labels are normalized when saved: their first letter is capitalized and duplicate labels on one bookmark are removed.

Build a useful tag system

  • Use stable categories: Work, Personal, Tools, Reading, Reference, and Projects are good starting points.
  • Tag by purpose: A bookmark can belong to both Work and Research.
  • Keep names short: Short labels scan and wrap more cleanly.
  • Use Temp intentionally: Temporary bookmarks receive a visible Temp tag automatically.

Category behavior

All bookmarks returns to the complete collection. A custom category shows cards containing that exact tag. The number beside a category counts saved bookmarks carrying it, not the number left after a search.

04 / navigate

Search and sort

The search field filters cards as you type and currently checks bookmark titles. On a desktop keyboard, press / from anywhere outside another input to focus search immediately.

Newest

The default view. Recently created bookmarks appear first.

Title A-Z

Alphabetical title order for finding a known name.

Category

Sorts by the first tag, then by title, to group related links.

No results

A clear empty-state message appears when a filter combination matches nothing.

05 / lifecycle

Use temporary bookmarks

Temporary bookmarks are useful for event pages, one-time forms, short research leads, and project links that should not become permanent clutter.

  1. Enable Temporary bookmark while creating or editing a bookmark.
  2. Choose a delete date and time; the time uses your browser's local time.
  3. Save it. Bookmarker adds Temp automatically.
  4. After the deadline, cleanup removes it when the app checks for expired items.

Expiration is permanent once cleanup removes the item. Export a backup first if you may need the link later.

06 / portability

Back up and restore

Open the gear menu beside Add bookmark to find the save-data tools. Exporting creates a JSON file containing the current collection; uploading restores a previously exported collection after validation.

Download save data

Choose Download save data. Your browser downloads a file named like savedbookmarks(YYYY-MM-DD).json. Export after a major cleanup, before clearing browser data, and before moving browser profiles.

Upload save data

Choose Upload save data and select an exported JSON file. Import replaces the current collection; it does not merge with it. Export your current collection first if you want a way back.

What is stored

Records include titles, URLs, image URLs, tags, creation times, and temporary expiration details. Data is stored locally in this browser; there is no built-in account or cloud sync.

07 / appearance

Images and automatic fallbacks

A custom image is optional. When Image URL is blank, Bookmarker derives the hostname from the bookmark URL and requests a Google-hosted favicon for that site. This provides a recognizable card image without requiring manual icon hunting.

  • Custom image URLs always take priority.
  • The fallback uses the website domain, not the bookmark title.
  • Sites without a useful favicon may return a generic or low-resolution icon.
  • Image services need an internet connection; the bookmark URL remains stored locally.

For the most consistent result, provide a direct image URL you trust. For quick setup, leaving the field blank is usually best.

08 / recovery

Troubleshooting

The bookmark will not save

Check Title and URL, confirm the URL includes a valid scheme, and fill both expiration fields if the bookmark is temporary. Unsafe protocols are intentionally rejected.

The card image is blank or generic

A custom image URL must point to the image file itself, not a page containing an image. Otherwise the automatic favicon service may be unavailable or the site may not provide a useful icon.

Bookmarks disappeared

Check that you are using the same browser profile. Local storage differs between browsers, devices, private windows, and profiles. Restore an exported JSON file through the gear menu.

Import reports invalid save data

Use a file exported by Bookmarker, not a screenshot or copied page. A valid file must remain a JSON array with a title, valid URL, and tags array in each record.

A temporary bookmark is still visible

Cleanup runs at startup and periodically while the app stays open. Reload after the expiration time if the app was closed at the deadline.
